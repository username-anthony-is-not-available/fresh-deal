# Vision: fresh-deal

> AI-powered meal planning that finds the best grocery deals for Quebec families.

## Target Users

- **Primary**: Budget-conscious families in Quebec wanting optimized grocery shopping
- **Secondary**: Meal preppers seeking deal-driven recipe suggestions

## Strategic Priorities (2025)

1. Implement real Playwright scrapers for Quebec grocery stores (Walmart, Provigo, IGA, Metro, Maxi)
2. Add user feedback and recipe rating system
3. Expand nutritional tracking and dietary restriction support
4. Build mobile-friendly or native app experience

## In Scope

- 7-day meal planning with breakfast, lunch, dinner
- Quebec grocery store deal aggregation
- Shopping list optimization by store
- Nutritional balance tracking
- AI-generated meal suggestions (OpenRouter/Claude)

## Out of Scope

- Grocery delivery integration
- Restaurant meal planning
- Non-Quebec store coverage (Phase 1)

## Success Metrics

| Metric                  | Current      | Target        |
| ----------------------- | ------------ | ------------- |
| Store coverage          | Mock data    | 5 real stores |
| Weekly savings estimate | None         | $30-50/week   |
| Recipe database         | AI-generated | 500+ curated  |

## Competitive Positioning

- **Primary competitors**: Flipp, Reebee, Mealime
- **Differentiation**: Quebec-focused, AI-generated plans, deal-first optimization, open-source

# Smart Meal Planner Mobile

This is the React Native mobile application for the Smart Meal Planner project.

## Features

- View meal plans
- Manage shopping lists
- Receive notifications about deals

## Getting Started

1.  Navigate to this directory: `cd smart-meal-planner/mobile/SmartMealPlannerMobile`
2.  Install dependencies: `npm install`
3.  Run the app: `npm run android` or `npm run ios`
